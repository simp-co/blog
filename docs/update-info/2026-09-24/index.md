# 2026年9月24日

目前这个博客基本上已经搭建好了，同时也找了一些之前写的东西放在这个博客上。目前这个博客主要使用了VitePress、Nginx、GitHub Actions，同时这个博客的代码也放在了GitHub上。

VitePress是一个静态站点生成器。说实话，本来我没打算使用这些SSG工具，因为我本来以为这些SSG工具生成的页面都是那种传统的静态页面，即每次请求的都是一个完整的页面。但是我想要的是像单页应用那样可以只请求必要的部分并在不刷新整个页面的情况下动态更新页面，所以我本来打算自己实现。后来在阅读vue的官方文档时了解到了VitePress，于是也去看了一下VitePress的文档。结果发现VitePress已经实现了类似的东西，VitePress可以使页面被访问之后对其进行“激活”，从而使其成为单页应用。

HTTP服务器使用的是Nginx。本来也考虑过GitHub Pages，但是想了想还是觉得自己搞个服务器好玩儿一些。

使用了GitHub Actions进行构建和部署，不然每次更新之后都要手动构建再部署太麻烦了。
