# 介绍

该部分为对Groovy官方文档的翻译及我写的部分批注组成的一些文章，是我于应该是2025年2月份左右阅读Groovy官方文档时所写。现在博客初建，把这些文章放在这里充充门面。

这些文章本来被写在并保存在一些本地的文档中，这些文档中包含着大量的从官方文档中的截图，如代码片段截图和其它原文内容的截图。考虑到图片体积以及网络传输图片时的成本等问题，在博客上的这部分文章如非必要将不使用截图，而是以文本的形式配合HTML/markdown中合适的元素或样式呈现。

注意：我在写这些文章的过程中可能对Groovy官方文档原文的内容做了一些取舍，取舍的主要动机应该是舍去那些冗余的或者是太过浅显以至于没有必要写的内容，因此这些博客文章的内容不一定可以严格对应Groovy官方文档原文。
